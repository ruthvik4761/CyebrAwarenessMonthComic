# Audio

`bgm.mp3` in this folder is currently a **3-second silent placeholder** (generated
so the project runs with no console errors out of the box). Replace it with the
real track before publishing:

1. Download the track:
   **"Crypto" by Kevin MacLeod**
   https://incompetech.com/music/royalty-free/mp3-royaltyfree/Crypto.mp3
2. Rename the downloaded file to `bgm.mp3`.
3. Drop it into this folder (`assets/audio/`), overwriting the placeholder.
4. Commit/upload the change to your repo.

## Want a different track instead?

Any track you drop in as `bgm.mp3` will work automatically — no code changes
needed, since `index.html` always looks for `assets/audio/bgm.mp3`. Just make
sure whatever you use is properly licensed for your use case.
